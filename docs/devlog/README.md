# Devlog

Short engineering journal. One file per sprint.

## How to use

After you finish a ticket, add a block in that sprint's file:

1. What you built
2. Why you made the important calls
3. What fought you
4. What you learned

Keep it short and in your own words. No polish required — clarity over vibes.

## Files

- `docs/devlog/sprint-01.md` — current sprint (OB-1 → OB-10)
- `docs/devlog/sprint-02.md` — nested traces work (OB-11+)
- Add `sprint-03.md`, etc. when the next sprint starts
